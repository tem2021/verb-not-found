VERB NOT FOUND — DEVELOPER CHEAT SHEET
========================================

WARNING: COMPLETE SPOILERS

This is a developer and live-performance rescue sheet. Commands shown in
CAPITALS may be typed in any capitalization. The parser compresses repeated
spaces and usually ignores articles only where the patterns below say so.


1. THE SHORTEST RELIABLE WALKTHROUGH
------------------------------------

ROOM OF NOUNS

  READ MESSAGES
  TAKE COMMA
  GO EAST

PRONOUN CORRIDOR

  READ MESSAGES
  GIVE ENVELOPES TO RECIPIENTS
  MEET SOMEONE
  EXPRESS YOURSELF
  GO NORTH

LIBRARY OF TENSES

  READ MESSAGES
  TAKE PRESENT
  GO EAST

CONDITIONAL COURT

  READ MESSAGES
  USE BOOK AS RACKET
  PLAY BADMINTON
  TAKE AND
  GO SOUTH

ROOM OF NOUNS — RETURN

  GO AND STAY

This reaches the principal ending, WE CONTINUE, with all 18 messages delivered
and all 7 missing verbs recovered.


2. ALL PUZZLE SOLUTIONS
-----------------------

PUZZLE 1 — LEAVE THE CLASSROOM

Required state:

  * The classroom message bundle has been read.
  * COMMA is in the inventory.

Commands:

  READ MESSAGES              (READ MESSAGE and READ BUNDLE also work)
  TAKE COMMA                 (GET COMMA and PICK UP COMMA also work)
  GO EAST                    (E and EAST also work)

Optional chalk branch:

  THANK TEACHER
  TAKE CHALK

THANK DESK also reveals the chalk. The chalk is not required because every
library route supplies a book, but taking it unlocks the alternate racket
solution and its unique court narration.

Reading this bundle recovers THANK, MEET, and STAY.


PUZZLE 2 — COMPLETE THE CORRIDOR

Required state:

  * The corridor bundle has been read.
  * All 4 sealed private messages have been delivered.
  * SOMEONE has been met.
  * The player has expressed themself.

Reliable commands:

  READ MESSAGES
  GIVE ENVELOPES TO RECIPIENTS
  MEET SOMEONE
  EXPRESS YOURSELF
  GO NORTH

Delivery alternatives:

  GIVE ENVELOPE
  GIVE MESSAGE
  DELIVER ENVELOPES
  DELIVER MESSAGES

Any command beginning with GIVE or DELIVER and containing ENVELOPE or MESSAGE
delivers all four sealed items. Their bodies are never displayed.

Meeting alternatives:

  MEET SOMEONE
  MEET STUDENT
  MEET PERSON
  SAY HELLO
  SAY HELLO TO SOMEONE
  ASK SOMEONE
  TALK TO SOMEONE

ASK/TALK only initiates the meeting when the line contains SOMEONE, STUDENT,
or PERSON. SAY HELLO always attempts the meeting. MEET must already have been
recovered from the classroom bundle.

Expression alternatives:

  EXPRESS
  EXPRESS YOURSELF
  EXPRESS SOMEONE
  EXPRESS TO SOMEONE
  EXPRESS PERSON

These solve the puzzle only in the corridor and only after meeting SOMEONE.
Reading the corridor bundle recovers EXPRESS.


PUZZLE 3 — CHOOSE A TENSE

First use:

  READ MESSAGES

Then choose exactly one of the three valid branches:

  PAST:       REMEMBER PAST
              REMEMBER BOOK
              REMEMBER
              TAKE PAST

  PRESENT:    TAKE PRESENT
              TAKE BOOK

  FUTURE:     WISH FUTURE
              WISH BOOK
              WISH
              TAKE FUTURE

Finally:

  GO EAST                    (E and EAST also work)

The first shelf selected permanently removes the other two. TAKE PAST requires
REMEMBER; TAKE FUTURE requires WISH. Both verbs are recovered by reading the
library bundle. PRESENT requires neither verb. All three choices are correct
and each adds a different line to the epilogue.


PUZZLE 4 — IMPROVISE A RACKET

First use:

  READ MESSAGES

Then assign either carried object the role of RACKET:

  USE CHALK AS RACKET
  USE CHALK AS A RACKET
  USE CHALK LIKE RACKET
  USE CHALK LIKE A RACKET

or:

  USE BOOK AS RACKET
  USE BOOK AS A RACKET
  USE BOOK LIKE RACKET
  USE BOOK LIKE A RACKET

CHALK works only if it was revealed and taken in the first room. BOOK always
works after one library shelf has been chosen.

SWING, HOLD, WIELD, MAKE RACKET, HIT, and STRIKE are recognized exploratory
verbs around this puzzle. They reach the same solution only if the complete
line still contains CHALK or BOOK plus AS RACKET, AS A RACKET, LIKE RACKET, or
LIKE A RACKET. WITH alone deliberately does not solve the puzzle; the contrast
between WITH and AS is part of the clue.

After a racket is ready:

  PLAY
  PLAY BADMINTON
  PLAY SHUTTLE
  PLAY GAME
  TAKE AND
  GO SOUTH

PLAY must have been recovered by reading the court bundle. Playing with chalk
breaks the chalk. Playing with the book marks it damaged and produces a unique
library complaint in the epilogue. TAKE/GET/PICK UP AND all work.


3. ALL ENDINGS
--------------

Every real ending requires all of the following:

  * The player has returned to the ROOM OF NOUNS.
  * AND is in the inventory.
  * All 18 messages have been delivered: 14 read publicly, 4 privately.

ENDING A — WE CONTINUE (principal / contradiction ending)

  GO AND STAY
  COMBINE GO AND STAY
  WRITE GO AND STAY
  WRITE CONTINUE
  WRITE WE CONTINUE

The parser accepts any WRITE text containing GO AND STAY or CONTINUE.

ENDING B — WE MET

  WRITE WE MET
  WRITE MET

ENDING C — WE REMEMBER

  WRITE WE REMEMBER
  WRITE REMEMBER

ENDING D — WE THANK

  WRITE WE THANK
  WRITE THANK

ENDING E — WE WISH

  WRITE WE WISH
  WRITE WISH

INTENTIONAL FALSE ENDING

  WRITE WE PLAY
  WRITE PLAY

This does not finish the game. The sentence asks for another turn. Any other
WRITE text also fails safely and lets the player try again.

There are 3 shelf outcomes x 2 racket outcomes x 5 true endings = 30 meaningful
end-state combinations. The chalk route is available only if chalk was taken;
the book route is always available. Command aliases do not create new states.

9. LIVE-PERFORMANCE RESCUE COMMANDS
-----------------------------------

If the audience is stuck, use HINT repeatedly. HINT is progressive within each
room and eventually prints an exact command. WORDS provides the short public
vocabulary reminder. HELP explains syntax without revealing solutions.

Useful developer invocations:

  make                       build the game
  ./verb-not-found           normal live mode
  ./verb-not-found -p        plain output, no ANSI screen control
  ./verb-not-found -f        skip every Enter pause
  ./verb-not-found -t        automated chalk/FUTURE/WE CONTINUE route
  ./verb-not-found -T        automated book/PAST/WE REMEMBER route
  make test                  run and verify both automated routes
  ./verb-not-found -h        show command-line flags

Do not use -f for the show: it removes the message and ending pauses that give
the narration room to breathe. Before performing, verify the laptop's local
clock and timezone because the epilogue reads the real system time. Use an
80-column-or-wider UTF-8 terminal with a monospace font.


10. FAST DIAGNOSIS
------------------

Cannot leave the first room:
  READ MESSAGES, then TAKE COMMA.

Cannot go NORTH from the corridor:
  READ MESSAGES; GIVE ENVELOPES TO RECIPIENTS; MEET SOMEONE;
  EXPRESS YOURSELF.

Cannot go EAST from the library:
  READ MESSAGES, then select exactly one tense.

RACKET NOT FOUND:
  USE BOOK AS RACKET, or use CHALK if it is in the inventory.

PLAY is rejected as a missing verb:
  READ MESSAGES on the court first.

Cannot take AND:
  Prepare the racket, then PLAY BADMINTON.

Final sentence says it is incomplete:
  Confirm the player is back in ROOM OF NOUNS with AND and SCORE reports
  Messages 18/18.

Need the most dependable ending command:
  GO AND STAY
